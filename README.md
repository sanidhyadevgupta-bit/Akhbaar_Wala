# Akhbaar Wala · अख़बार वाला · છાપાવાળો

A one-thumb hyper-casual game for the **Dainik Bhaskar Game Jam**. Ride a paperboy's cycle through a dawn mohalla and land the morning paper on every subscriber's porch.

By **Sanidhya Dev Gupta** (catsarewhat).

- `index.html` is the case study: brief, audience, design process, mechanics, art direction and tools, with the playable build embedded.
- `game.html` is the full game in a single file (three.js + Web Audio, no image or audio assets).

## Play
- Case study and game: hosted on GitHub Pages from this repo
- itch.io: https://catsarewhat.itch.io/akhbaar-wala

## Controls
Tap the left third of the screen to throw left, the right third to throw right, and the middle to hop. Keyboard: ← ↑ →, Esc to pause.

## Run locally
Open `index.html` in a browser, or serve the folder (for example `python3 -m http.server`) so the embedded game loads.

## Built with
three.js r128, Web Audio API, HTML/CSS/JavaScript, Google Fonts. Built with Claude (Anthropic) as an AI coding partner.
